# tel-ogtm

URLに含まれた電話番号を正規化し、「電話をかける」ボタンを表示する小さなCloudflare Workerです。ボタンを押すと端末の電話アプリが開きます。

画面には電話番号、Font Awesome Solidの電話アイコン付き発信ボタン、プロジェクトへのGitHubリンクを表示します。

## 使い方

- `/090-1234-5678` → 表示: `090-1234-5678` / 発信先: `tel:09012345678`
- `/%2B81%2090%201234%205678` → 表示: `+81-90-1234-5678` / 発信先: `tel:+819012345678`
  入力には数字、先頭の `+`、空白、ハイフン、丸括弧、ピリオドを使用できます。正規化後は3〜15桁、国際番号は `+` に続いて1〜9の数字で始まる必要があります。国内番号と `+81` の国際番号は、一般的な日本の電話番号表記に整えて表示します。

`/` はプロジェクトのGitHubリポジトリへリダイレクトします。電話をかける場合は電話番号をURLパスに含めてください。

## 開発

Node.js 24を使用します。

```sh
npm ci
npm run dev
```

開発サーバーは全ネットワークインターフェースのポート8787で待ち受けます。LAN内の別端末からは `http://<開発PCのIPアドレス>:8787/` にアクセスできます。

主なコマンド:

- `npm run check` — 整形、型、Tailwind CSSビルド、テスト、Workersバンドルを一括確認
- `npm test` — Workersランタイム上でテスト
- `npm run cf-typegen` — Wrangler設定から型を再生成
- `npm run deploy` — Cloudflareへデプロイ

## プライバシー

電話番号はURLに含まれるため、ブラウザ履歴、共有先、Cloudflareのリクエストログ等に残る可能性があります。レスポンスには `Cache-Control: no-store` と `Referrer-Policy: no-referrer` を設定していますが、機密性の高い番号の共有には使用しないでください。
